# Changelog

All notable changes to CleanGenius AI will be documented in this file.

## [1.0.0] - 2024-12-15

### Added
- Complete AI-powered Windows disk cleanup desktop application.
- Multi-mode scanner engine (Fast, Deep, Custom, Registry).
- DeepSeek AI integration (primary default provider with `deepseek-chat` and `deepseek-coder`).
- Multi-AI provider support (OpenAI, Anthropic Claude, Google Gemini, Ollama).
- Safety manager with 3-level checks (Protected path, active process lock, system attribute).
- Instant rollback system backing up files prior to cleanup.
- Real-time monthly AI API usage & cost tracking dashboard.
- IObitASC-inspired dark theme UI with custom frameless titlebar.
- Cross-platform test suite and GitHub Actions workflow setup.
