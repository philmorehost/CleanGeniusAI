# Contributing to CleanGenius AI

Thank you for your interest in contributing to CleanGenius AI!

## Development Setup

1. **Clone repo**:
   ```bash
   git clone https://github.com/yourusername/cleangenius-ai.git
   cd cleangenius-ai
   ```

2. **Install Node & Python Dependencies**:
   ```bash
   npm install
   pip install -r requirements.txt
   ```

3. **Run Test Suite**:
   ```bash
   npm test
   ```

4. **Start Application**:
   ```bash
   npm run dev
   ```

## Coding Standards
- **Python**: Follow PEP 8 guidelines. Use type annotations where appropriate.
- **JavaScript**: Modern ES6+ syntax.
- **Security**: Never commit real API keys or sensitive user tokens.
